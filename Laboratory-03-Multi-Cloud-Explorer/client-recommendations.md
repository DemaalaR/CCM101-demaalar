# Client Recommendations


## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because it provides a wide range of cloud services that can support a startup as it grows. The startup can begin with smaller resources and scale them as the mobile application's users increase. AWS also provides flexible and scalable services that can help control infrastructure costs.

### Recommended Services

- Amazon EC2 – for running application servers
- Amazon S3 – for storing application files and data
- Amazon RDS – for managing the application's relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make cloud migration and identity management easier. The university can also use Azure services to support hybrid cloud environments.

### Recommended Services

- Azure Virtual Machines – for migrating Windows Server workloads
- Microsoft Entra ID – for identity and access management
- Azure Blob Storage – for storing documents, backups, and other university data

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is recommended because it has strong capabilities in artificial intelligence, machine learning, data analytics, and high-performance computing. Google Cloud provides specialized infrastructure and AI services that can support the development and training of machine learning models. Its managed Kubernetes platform also helps organizations deploy and scale containerized AI applications.

### Recommended Services

- Compute Engine – for high-performance computing workloads
- Vertex AI – for developing and deploying AI and machine learning applications
- Google Kubernetes Engine (GKE) – for deploying and managing containerized AI applications

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because the company requires highly available infrastructure that can support customers around the world. AWS provides a global infrastructure and services that can automatically scale resources based on application demand. Its load balancing, computing, and database services can help maintain application availability during periods of high traffic.

### Recommended Services

- Amazon EC2 – for running scalable application servers
- Elastic Load Balancing – for distributing traffic across application resources
- Amazon RDS – for managing the company's relational database

- ## Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS provides a broad range of scalable services that allow startups to begin with smaller resources and expand as their business grows. |
| Enterprise Organization | AWS | AWS offers a wide range of enterprise services, global infrastructure, security features, and scalability for large organizations. |
| Microsoft Environment | Azure | Azure is the best choice because it integrates closely with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning | GCP | GCP is a strong choice for AI and machine learning because it provides advanced AI services, high-performance computing, and data analytics capabilities. |
| Kubernetes Deployment | GCP | GCP is well suited for Kubernetes deployments because it provides Google Kubernetes Engine (GKE), a managed Kubernetes service. |
| Global Web Application | AWS | AWS provides extensive global infrastructure and scalable services that can support highly available web applications serving users around the world. |
