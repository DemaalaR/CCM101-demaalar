# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is Amazon Web Services (AWS). I was impressed by its wide range of cloud services, global infrastructure, and flexibility for different types of organizations. AWS provides services for computing, storage, databases, networking, security, and application development. I also found it suitable for both startups and large enterprises because resources can be scaled according to business needs.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and Google Cloud Platform (GCP) provide similar fundamental cloud services. All three offer virtual machines, object storage, databases, networking, identity and access management, and Kubernetes services. They also support scalable infrastructure, high availability, security features, and pay-as-you-go cloud computing models.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when selecting a cloud platform because organizations have different goals, budgets, technologies, and workloads. For example, a company using Microsoft technologies may benefit more from Azure because of its integration with Windows Server, Microsoft 365, and Microsoft Entra ID. An organization focused on artificial intelligence may prefer GCP because of its strong AI and machine learning capabilities.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider is not simply about selecting the most popular platform. A Cloud Solutions Consultant must understand the client's business requirements and match them with appropriate cloud services. I learned how to compare cloud platforms, analyze technical requirements, and justify recommendations based on scalability, compatibility, performance, and business needs.

## 5. How has your GitHub Cloud Computing Portfolio improved?

My GitHub Cloud Computing Portfolio has become more organized and informative after completing this mission. I added research about AWS, Azure, and GCP, comparison tables, client recommendations, a decision matrix, Linux investigation results, and screenshots as evidence. This mission also improved my confidence in using GitHub to document technical work and demonstrated how cloud computing concepts can be applied to real business scenarios.
