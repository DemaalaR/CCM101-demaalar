# AWS Research


## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of services for computing, storage, databases, networking, security, analytics, and application development. Organizations can use AWS to build, deploy, and scale applications without maintaining all of their physical infrastructure.

## 2. Global Infrastructure

AWS operates a worldwide infrastructure made up of Regions, Availability Zones, Local Zones, and Wavelength Zones. AWS currently has 39 geographic Regions and 123 Availability Zones. Each AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This structure helps organizations design applications with high availability and fault tolerance.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface for accessing and managing AWS services and resources. It can be used to manage services, monitor usage and account health, and view billing information.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

### Amazon S3

Amazon Simple Storage Service (S3) provides scalable object storage for files, backups, application data, and other information.

### Amazon RDS

Amazon Relational Database Service (RDS) is a managed service for running relational databases in the cloud.

### AWS Lambda

AWS Lambda is a serverless computing service that allows organizations to run code without managing servers.

## 5. Three Advantages

1. **Scalability** – AWS resources can be increased or decreased according to changing workloads.
2. **Global Infrastructure** – AWS provides infrastructure across many geographic regions, allowing organizations to deploy applications closer to their users.
3. **Wide Range of Services** – AWS provides many cloud services that support different technical and business requirements.

## 6. Typical Enterprise Use Cases

AWS is commonly used by enterprises for:

* Hosting websites and business applications
* Data storage and backup
* Database hosting
* Disaster recovery
* Application development and testing
* Data analytics
* Artificial intelligence and machine learning
* Migration of on-premises infrastructure to the cloud
