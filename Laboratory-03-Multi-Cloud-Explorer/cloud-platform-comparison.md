## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services among the three major providers. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with products and services such as Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in Artificial Intelligence, data analytics, and Kubernetes. Google created Kubernetes and offers Google Kubernetes Engine (GKE), along with a wide range of AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and gives organizations many options for building and scaling applications. Its extensive global infrastructure and service portfolio make it suitable for different types of business requirements.
